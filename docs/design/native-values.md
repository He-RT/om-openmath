# 原生结构值与科学诊断

`ResultPresenter` 在文档内按原 result_ref 拥有只读展示。矩阵、列表、记录、DataTable 通过现有 `InspectResultPage` 读取原 retained value；原 cell/out/view、当前文档代次和主 scope 仍由 `ResultClient` 核对。分页、展开和源码复制均不调用主求值器。主结果修改期间到达的旧回复不能更新展示，合法历史值通过原引用读取。

系统 `NSTableView` 显示矩阵/列表/表格，系统 `NSOutlineView` 显示记录字段及其真实值。字段展开后，可双击真实值行或选择并按 Return 读取，选择将键盘焦点交给该 Outline。Outline 节点身份在同页内稳定，折叠和展开只作用于已经取到的实际条目；进入容器才请求真实路径，返回上层再次请求原路径/页。默认 32 行、8 列，协议最多 100 行、32 列及路径 32 层。用户看到的行列序号从 1 开始，发送给内核的表达式路径和 offset 从 0 开始。表格列标签由内核列页提供，不能把 record 的内部字段顺序当表格列序。

核心现有回复预算另限 256 KiB，因此合法行列上限不保证同时容纳所有字符串/源式。拒绝大页时保留当前已读取页并显示真实失败；首次页面过大仍保留经过 scope 核对的已接纳 summary/presentation 和完整原式入口。完整源式沿原 16 KiB UTF-8 分块、总字节数和 SHA 校验路线取得，最大 8 MiB。原 64 MiB/32 个结果快照的保留边界不提高；引用被淘汰时显示实际不可用，不运行旧输入恢复画面。

每个值保留真实 kind、nature、count、稳定 occurrence ID 和原源式。整数、有理数、高精度原数从未转换为 Double 来显示、排序或复制。表头不提供排序。叶值超过屏幕长度时明确标注摘录，页面复制也带有“OpenMath 页面摘录”标题；完整当前值的 Modern/Wolfram/LaTeX 复制单独读取真实路径的源式。剪贴板成功提示须同时满足 `NSPasteboard.setString` 接纳及完整 UTF-8 回读一致。摘录没有“作为新源码”入口。

科学含义须同时满足根路径为空和真实 `ScientificOrigin` 非空。收敛状态、方法、残差/误差估计和保证标签只解释实际 callback 的机器字段；仍保留原字段名、原字符串和值。任意 `converged:true` 或 `guarantee:"certified_global"` 记录、缓存结果、包装结果及嵌套记录不能取得科学标签。误差估计不显示为证书，数值候选不显示为精确全局认证。

单位、插值、拟合模型与有限级数使用内核真正提供的 kind 和源式显示根摘要/原始定义，并提供真实完整源码读取和已有数值投影操作。拟合中的数据表来自实际样本和预测，模型/插值定义不会根据名字在界面生成曲线；采样和二维渲染仍由 R4.2.12 提供。树深度达到协议边界时禁止继续请求更深路径，原完整根源式仍保留全部数据。

开发证据见 [R4.2.10记录与原始输入/输出](../acceptance/pre-alpha.4/development/r42/native-values.json)。它只贡献对应展示 case，不替代同一最终 candidate 的 32 项运行和发行 gate；系统候选窗口、长笔记本性能、Markdown/步骤/绘图仍由各自任务验收。
