## 计算与数据规格

### 基础与线性代数

补齐数值范围、精度查询、十进制构造、互补反双曲及erf/erfc/Gamma/Beta。Gamma/LogGamma/Beta首版正实机器路径，Gamma正整数提供精确阶乘关系；复杂分支和任意精度明确后续。除十进制构造/现有高精度能力外，选项不能制造新的高精度算法。

基础矩阵支持精确有理数与机器实数，复用现有Bareiss；向量内积与伴随遵守复数共轭。数值分解首版稠密≤64×64：LU部分选主元、QR Householder、Cholesky正定检验、SVD一侧Jacobi、实对称特征系统Jacobi；非对称/复特征系统、广义稀疏/张量后续。欠定、奇异、病态与维度问题明确区分；显示残差不意味着严格认证。

统计样本方差/协方差默认n−1，允许显式总体n；分位数采用type7线性插值。空样本/样本不足/零方差相关明确失败。随机使用SplitMix64默认会话seed=0；显式seed创建局部流，不推进主会话；只读工具也不推进主随机状态。CSV/JSON只处理数据；文件读取交给宿主，不在纯CAS中引入IO。

单位支持SI基本维度、前缀和固定复合换算，因子保持精确；加减量纲必须兼容。首版不含摄氏等仿射温标、货币和联网知识库，也不声称能求解所有带单位的符号方程。

### 微积分、ODE与优化

符号积分限：多项式、可识别线性初等与链式形式、有限分部积分、一次/二次因子有理函数、Gaussian→Erf。根据条件与主值分支输出真实表达式；无算法时保留输入，不能靠附近采样宣称符号解。

数值积分：一维Gauss–Kronrod15/7，自适应拆分、有限/无限端点变换与显式断点；机器路径，默认abs_tol=1e-10/rel_tol=1e-8；预算、奇点、误差停滞或不收敛返回诊断。估计误差不命名为严格包围区间。

极限覆盖有理式和明确初等形式，包含左右/双侧/无穷；Taylor阶数0..64，系数由真实求导获得，明确O项，极点/分支点拒绝普通Taylor。常规series_coefficient不能把截断范围外的项当作零。

ODE：机器实数状态≤64维、非刚性初值问题，Dormand–Prince5(4)，默认abs_tol=1e-10/rel_tol=1e-8/max_steps=100000；连续插值，简单零交叉终止事件，时间可反向。普通interpolate支持linear/hermite且默认拒绝外推。刚性、DAE、PDE及通用符号ODE不列入本版。

优化：goal=min/max，scope=local默认；一维有界Brent与多变量BFGS/盒约束投影；global仅对可认证凸二次子集开放。Mathematica的Minimize/NMinimize兼容名不可以伪装成局部保证。拟合使用线性QR与非线性Levenberg–Marquardt、最多16参数；提供真实残差与状态，未计算的统计属性不显示成功。

## 架构与平台接口

- 新增纯数值分析层，仅依赖底层数值/Interrupt；算法接受纯回调，不解析源码、不打开文件、不访问网络，核心继续forbid unsafe和WASM可用。
- 函数描述包含规范名/兼容名、参数角色/默认值、保持语义、pipe位置、返回/精度/支持范围与平台。GetFunctionCatalog/GetCapabilities为新增查询；保持旧协议字段和Wolfram InputForm。
- 表格、记录、单位、插值及NumericDiagnostics为新结果对象；误差/收敛、精确/近似、局部/全局、范围限制使用不同可读状态，默认Solve规则结果不替换成新对象。
- 新增Scene3DRequest/Scene3DData及采样接口，不给旧PlotData的二维坐标偷偷加第三项。内核生成几何/网格/颜色，WebGL2只做相机与渲染。
- 二维仍采用桌面/Web原绘图容器与iOS原生Canvas；三维桌面/Web原生WebGL2，无新三维框架。场景含有限图元、变换、颜色和透明度；资源预算明确且所有点/索引/颜色检查有限值。
- 缺少WebGL2或iOS三维：明确功能/平台说明，保留源式与可用导出；不把投影示意图称为三维支持。iOS不为不展示的场景自动做大网格采样。
- explore使用单独参数作用域，支持数值滑块与标量/矩阵/二维图/桌面三维；不改主会话变量，变化、切文档、后台和取消隔离旧回复。
- 导出：表格CSV/JSON、二维SVG/PNG、三维OBJ；CLI导出不依赖交互窗口。既有Markdown/LaTeX导出不能让新类型丢失源码或泄漏凭据。
- 不新增第三方数学运行时/三维框架；如果后续确实需要依赖，先单独记录必要性、许可、WASM和Rust1.94兼容证据。

2026-10-05，用户明确要求本轮把预留写进计划。以下为设计约定，尚未实现；不改变 `.3` 的科研功能主线，不安装 Pi/Rig，也不提前开放写入工具。Agent 运行时、右栏提示词管理和批量事务的完整实现另立后续任务。

### 本阶段需要准备的元数据与边界

- 函数 `id` 为稳定身份，规范名称和别名可以演进；提示词、工具描述、帮助和补全引用同一目录。参数在 R3.1 接入时增加可验证的类型、必填标志、枚举、范围及实际默认值；当前目录中的「必填」「省略」等说明不得直接充当工具参数默认值。结构化返回说明要区分值、精确/近似、条件、收敛状态、误差估计及不支持原因。

本轮已将文档身份分配、身份账本和副作用预留写进机器可读目录；这些仅完成R3.0，仍未实现工具schema、权限执行或GetCapabilities接口。后续六个Notebook入口在目录中均为deferred、无runtime_names/当前平台，不纳入 `.3` 的执行工具承诺。
- 为执行入口预留副作用分类：`pure`、`read_session`、`write_session`、`write_document`、`host_io`。未知入口不自动授予权限；用户函数/参数表达式仍可能有副作用，只读工具必须在受约束的只读环境执行，不能仅相信顶层标签。修改随机状态也属于会话写入。
- `GetFunctionCatalog` / `GetCapabilities` 的实际接口携带描述版本，并区分当前内核能力、宿主展示能力和任务获准能力。规划/未实现条目不能进入可执行工具集合；文档浏览可以单独包含它们。快照和工具结果保留稳定单元格ID、结果对应的源码版本及是否过期，不以模型文字代替真实状态。
- 业务类型和公共协议属于 OpenMath，不能依赖 Pi 的 `AgentTool`、Rig 的运行状态或某个提供商消息对象。后续适配器只负责参数、事件和结果转换；框架选型不能改变函数语义或文档格式。

### 事务与任务接口的预留契约

后续应用层接口统一为 `read_notebook`、`apply_notebook_patch`、`run_cells`、`get_function_docs`，另提供界面控制使用的 `undo_transaction` 与 `cancel_task`。这组名称是预留，不表示当前已存在可调用工具。

- 使用 `document_id` 和打开文档的代次界定操作范围；`document_revision` 对成功的源码/顺序/标题变更单调递增。手工编辑与 Agent 编辑最终进入同一写入队列；提交前同步已确认草稿，IME合成中的单元格不能被Agent覆盖或强行提交。
- Patch 携带预期文档版本、唯一 `operation_id` 与操作列表；后端检查任务范围及权限，在临时文档上验证全部结构变更，成功才一次提交。冲突返回结构化错误和当前版本，不静默覆盖。相同操作ID与相同内容重试返回原回执；相同ID配不同内容拒绝执行。
- 批量事务不能简单循环调用当前单项编辑请求：尤其不能在中间删除时触发依赖计算。原子提交只处理源码、依赖失效与变更事件，计算通过独立的 `run_cells` 请求进行。计算绑定源码版本与任务ID，旧回复不能覆盖新编辑；取消计算不伪称回滚已提交的编辑。
- 提交回执包含事务ID、版本与实际变更，供宿主生成修改记录和撤销。撤销使用反向操作并检查被修改内容是否仍匹配；不以整个旧笔记本快照覆盖之后的手工编辑。撤销后的相关结果标为待重算，不直接恢复为有效旧输出。
- 预留框架无关的任务/请求ID、流式进度、结构化错误与结束状态；模型调用和工具计算的取消信号传给现有中断机制。权限由宿主/内核校验，提示词和模型传入参数不能自行授予权限。
- 「编辑已应用」「执行完成」「文件保存成功」分别确认；持久化成功必须等待现有文件层回读/完成回执。继续保持 `.omnb` v1 仅存源码的约定，Agent会话、提示词版本、操作日志、任务权限和凭据独立存储，不写入笔记本或数学导出。

### 后续实现时的验收预留

验证手工编辑/Agent修改的版本冲突、IME保护、文档切换与迟到回复、非法操作导致整笔不提交、重复请求不重复插入、批量删除不暴露中间计算、撤销不覆盖后续编辑、执行失败/取消仍保留已提交源码、保存失败不宣称已保存。业务层测试不依赖 Pi/Rig；各适配器复用同一套接口契约。上述运行时测试属于后续任务，本轮只确认规格完整和未冒充实现。

## 场景与验证

### 必须交付的两个场景

1. 地月L2：圆型限制性三体模型、质心原点及地心原点、a=384400km、GM_E=398600.435507/GM_M=4902.800118 km³/s²；求月球外侧根，分别输出约444244.2226/448914.9072km、距月球64514.9072km，显示真实平衡残差和按位置比例的二维示意。参数来自标称值，数值位数不等于物理准确度。
2. 西瓜：桌面/Web参数曲面条纹、浅色皮层、红色切面、瓜籽、场景变换与光照；可旋转缩放复位，颜色来自内核，OBJ导出再读取几何。iOS明确此场景尚未适配。

### 门禁

- 原53语料和数学期望不改；精确用恒等式/证书，数值用独立参考、收敛阶与残差，不仅复算同一算法。
- 模式、空数据、零向量、奇异/非正定、单位冲突、无效方法/精度/维度、积分奇点、优化/ODE不收敛、预算/取消均有拒绝或明确未求值用例。
- 语法往返、别名冲突、lambda作用域、pipe只求值一次、参数默认值、返回形状和SourceSpan/IME测试。
- 数据/显示/参数探索/导出的跨端真实流程、旧回复与文档代次隔离、后台和保存期间编辑。
- 原Rust/Clippy/fmt/cargo-deny/WASM/协议漂移/前端/Swift/附件门禁保留；本机禁止启动模拟器，iPhone/iPad模拟器只在GitHub runner执行。
- 文档生成无漂移，已实现有真实注册与证据，计划例注明版本，数学保证/精度/平台限制都可查询。版本、标签、所有附件和SHA256来自同一发行源码；保留.1/.2。
