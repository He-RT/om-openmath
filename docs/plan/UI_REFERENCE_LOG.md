## 观察转成产品决定

| 实际观察 | 对 OpenMath 的决定 | 实施状态 |
|---|---|---|
| 多数应用用固定工具栏、清楚的选中项和稳定的内容区；标题不与工具争抢 | 主区突出源码与结果，目录只负责定位；顶栏保留运行、保存、助手、详情等高频入口 | D066、D069 已实现；新建收进文件菜单，运行有文字标签 |
| 字体册的信息检查器按需出现，关闭后内容立即获得空间 | 详情可收起，文档 / 结果 / 步骤有可见选择，避免靠多个难辨图标切换 | D069 已实现 |
| 快捷指令的分类→详情→流程逐层展开；“制作语音音频”先显示一行，展开后才出现速率、音高、语言 | 结果先给答案与必要条件，推导、参数、完整统计按需展开；每个展开动作留在所属内容附近 | 结果菜单、步骤树、图形信息已具备；无需为参考再改架构 |
| 快捷指令详情仅一个明显的主操作，描述与属性分列；其彩色卡片用于可挑选的项目 | 本工作区不复制彩色卡片网格；计算单元用排版、间距与轻分隔建立关系 | D066–D069 已采用；后续保持 |
| 地图把搜索放侧栏，内容铺满画布，缩放 / 模式固定在边缘；切模式不搬动主要控件 | 几何图形优先占用结果宽度，缩放、复位保持固定位置，信息与限制收进局部面板 | D068 已实现；D069 补易读刻度、轻网格、零轴 |
| 地图长详情滚动后，顶部仍保留当前地点标题与关闭动作，底部操作位置稳定 | 长结果 / 助手阅读时保持所在单元和停止入口可辨；不增加覆盖正文的浮动工具排 | 原生工具栏已有稳定停止位置；安装版停止仍需实际核对 |
| 磁盘工具将名称、类型、容量概览放前面；大量技术字段另进简介的两列表格 | 日常结果只显示有用摘要；版本、引用、诊断等放详情；标签和值对齐，不堆成一段小字 | 已有详情与版本页；不照搬磁盘操作工具栏的全部按钮 |
| 音乐 / 时钟的主状态清楚，次要动作在更多菜单；访达在多视图间维持对象身份 | 运行 / 停止使用同一位置，切换显示不重算、不改变原结果身份 | 已实现，继续保持现有原 ID / 结果引用边界 |
