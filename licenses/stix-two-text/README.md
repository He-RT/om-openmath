# STIX Two Text

Unmodified Google Fonts WOFF2 distribution (v18), downloaded 2026-10-17.
Includes 400 normal, 600 normal and 400 italic, with the upstream Latin, Greek and Cyrillic Unicode subsets. The local CSS preserves upstream Unicode ranges.

Runtime requests use only local font files. See `manifest.json` for original URLs and SHA256, and `OFL.txt` for the complete license and copyright notice. No font outlines or names were modified.
