# 原生自有测试输入

所有图片、PCM 音频、PDF 和视频均由本目录源码生成，不读取用户私件。测试字节以 `manifest.json` 的 SHA256 封存；内容声明 CC0-1.0，生成器沿仓库 MIT/Apache-2.0。视频由 SDK27 系统 H264 编码器生成，重编码的容器字节可能不同；验证使用封存的原件，不能用重新生成的相似画面替代原散列。

- PNG：sRGB 图案与自绘 `2+2=4` 字形，不随包复制系统字体。
- WAV：16kHz 单声道、1 秒 220Hz 正弦，明确没有语音或转写参考。
- PDF：自有数学文本及标准 Helvetica 引用，不嵌入第三方字体。
- MP4：128×96、10 帧/10fps、移动白色标记，无音轨。
- 网络：固定 JSON、分段 Unicode SSE、错误 UTF-8。仅回环 HTTP 服务提供真实 401/429/500、302 和超时。
- I/O：子进程在打开/写入/fsync/rename/目录同步处真实停住后由父进程 SIGKILL；ENOSPC 是明确注入错误，绝不返回成功。进程中断不能证明断电耐久，SQLite 事务故障与平台同步仍由存储门禁单独核验。

`python3 .../Fixtures/check.py` 只测试输入与基础故障机制；没有伪造业务 handler、CAS、OCR、ASR、工具结果或持久化回执。输出和残留文件保留在仓库 `target/native-fixture-attempts/`。媒体解码与模型协议覆盖在对应实现任务接入。
